## 📖 Overview

**Airplane Passenger Mockup Workshop** is a frontend UI mockup project that recreates the passenger experience inside a modern airline application.

The goal of this workshop is to practice **UI/UX design**, **responsive layouts**, and **interactive frontend components** using pure web technologies.

This project simulates an airline passenger dashboard including flight information, boarding passes, seat selection, travel status, and booking components.

---

## 🎯 Features

- 🎨 Modern airline-inspired interface.
- 📱 Fully responsive design.
- 🎫 Digital boarding pass layout.
- 💺 Interactive seat selection mockup.
- 🛫 Flight information cards.
- 🌍 Passenger travel dashboard.
- ✨ Smooth animations and transitions.
- 🧩 Clean component-based frontend structure.

## ⚙️ Installation

Clone the repository.

```bash
git clone https://github.com/diarpicu2022-commits/Airplane-passenger-mockup-workshop.git
```

Move into the project folder.

```bash
cd Airplane-passenger-mockup-workshop
```

Open the project.

```bash
# VS Code
code .

# Or simply open index.html in your browser.
```
